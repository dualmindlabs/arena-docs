<Update label="October 2026" description="Docs and website" tags={["Docs", "API"]}>

<Update label="September 2026" description="Reliability" tags={["API", "Fix"]}>
  ## More reliable data access

  The API now attaches its service credentials to every database request, fixing intermittent failures when loading threads, models and the leaderboard.
</Update>

<Update label="August 2026" description="The API moves to Cloudflare" tags={["API", "Infrastructure"]}>
  ## API on Cloudflare at api.dualmindlab.tech

  The DualMind API moved from Azure App Service to **Cloudflare Containers**, served at `https://api.dualmindlab.tech`.

  - The Arena now talks to the new URL.
  - A scheduled ping keeps the API warm, so requests rarely wait on a cold start.
  - A smaller container image with a ReadyToRun build starts faster.
  - Deploys run automatically from GitHub Actions.

  ## Scaling experiments

  - `GET /health` now includes an `instanceId` showing which API instance served the request.
  - We trialled spreading traffic across several instances, then returned to a single always-warm instance while shared state is built. More on the [roadmap](/roadmap).

  ## Arena

  - An early-access waitlist page went live at [early.dualmindlab.tech](https://early.dualmindlab.tech).
  - The Arena codebase was cleaned up and now runs lint checks in CI.
</Update>

<Update label="March 2026" description="New providers and fallback" tags={["Models", "API", "Arena"]}>
  ## Cloudflare Workers AI models

  30+ open models from Cloudflare Workers AI joined the Arena, including Llama 3.x, Mistral, Qwen, QwQ, DeepSeek R1 distills, Gemma and Granite. They're available when you pick them in Side by Side or Direct Chat. The ELO leaderboard was set up for the new roster.

  ## Google AI Studio models

  Gemini and Gemma models are now available through Google AI Studio. The Bytez provider was retired.

  ## Automatic fallback

  If a model is unreachable or times out, a basic fallback model answers instead and the reply starts with a **[System Note]**, rather than the battle failing.

  ## Arena

  - Redesigned sign-in and sign-up screens.
  - Welcome emails for new accounts.
  - A redesigned leaderboard with an explanation of ELO.
</Update>
