# Changelog

Stay up to date with the latest improvements to DualMind Arena.

<Update date="2026-02-07" version="2.0.0">
  ## Arena 2.0 Launch

  Major platform upgrade delivering a comprehensive blind comparison experience.

  ### Features
  - **Interactive API Playground**: Test API endpoints directly from the documentation.
  - **Community Leaderboard**: Real-time ranking of models based on thousands of user votes.
  - **Enhanced Sharing**: Share specific comparisons or entire conversation threads with public links.
  - **Mobile Optimization**: Fully responsive design for voting on the go.

  ### Documentation
  - Complete rewrite of public documentation
  - New guides for "How it Works" and "Model Comparison"
</Update>

<Update date="2025-01-15" version="1.5.0">
  ## Topper Mode & Analytics

  ### Features
  - **Topper Mode**: Challenge the current #1 model against random challengers.
  - **Text-to-Speech**: Listen to model responses (accessibility feature).
  - **Improved Thread Management**: Better organization for your conversation history.
</Update>

<Update date="2024-12-01" version="1.0.0">
  ## Public Beta

  Initial public release of DualMind Arena.
  
  - **Dual Chat**: Compare two models side-by-side.
  - **Voting**: Submit preference for A or B.
  - **Basic Accounts**: Save your history.
</Update>
