# MCP Server

DualMind Lab provides a **Model Context Protocol (MCP)** server that allows AI agents and IDEs to interact with the platform's API, database, and documentation directly.

## What is MCP?

The [Model Context Protocol](https://modelcontextprotocol.io) (MCP) is an open standard that enables AI systems to connect with external data sources and tools. It allows AI agents like Claude, Cursor, and others to:

- Query your API documentation
- Access database schemas
- Execute API requests
- Retrieve real-time data

## IDE Integration

### Cursor IDE

Add DualMind Lab context to Cursor:

1. Open **Cursor Settings** → **AI** → **Context**
2. Add the following URLs as context sources:
   - `https://docs.dualmindlab.tech/skills.md`
   - `https://docs.dualmindlab.tech/llms.txt`
   - `https://docs.dualmindlab.tech/api-reference/openapi.json`

### Claude Desktop

Configure Claude Desktop to use DualMind Lab MCP:

```json
{
  "mcpServers": {
    "dualmind": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-http",
        "--url",
        "https://docs.dualmindlab.tech"
      ]
    }
  }
}
```

### Other AI Agents

Any MCP-compatible agent can connect using:

- **Base URL**: `https://docs.dualmindlab.tech`
- **OpenAPI Spec**: `/api-reference/openapi.json`
- **Skills Context**: `/skills.md`
- **LLMs Context**: `/llms.txt`

## Quick Commands for AI Agents

When working with DualMind Lab, AI agents can reference:

| Command | Resource | Description |
|---------|----------|-------------|
| `Read skills.md` | Project context | Full architecture and API overview |
| `Read llms.txt` | LLM context | Concise reference for code generation |
| `GET /api-reference/openapi.json` | API spec | Complete OpenAPI 3.0 specification |
| `Query database schema` | Schema docs | PostgreSQL table definitions |
