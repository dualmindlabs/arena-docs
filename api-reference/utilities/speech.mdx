---
title: "Text to Speech"
api: "POST https://api.dualmind.ai/v1/speech/generate"
description: "Generate speech audio from text using DualMind's TTS service."
---

## Authentication

No authentication required. This endpoint is publicly accessible.

## Request

<ParamField body="text" type="string" required>
  The text to convert to spoken audio.
</ParamField>

<ParamField body="voice" type="string">
  Voice identifier. Defaults to `"Celeste-PlayAI"` if not provided.
</ParamField>

<RequestExample>
```bash cURL
curl -X POST https://api.dualmind.ai/v1/speech/generate \
  -H 'Content-Type: application/json' \
  -d '{"text": "Hello, this is a test.", "voice": "Celeste-PlayAI"}' \
  --output speech.wav
```

```javascript JavaScript
const response = await fetch('https://api.dualmind.ai/v1/speech/generate', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ text: 'Hello, this is a test.' })
});
const audioBlob = await response.blob();
```

```python Python
import requests

response = requests.post(
    'https://api.dualmind.ai/v1/speech/generate',
    json={'text': 'Hello, this is a test.', 'voice': 'Celeste-PlayAI'}
)
with open('speech.wav', 'wb') as f:
    f.write(response.content)
```
</RequestExample>

## Response

**Content-Type**: `audio/wav`

On success, the response body contains binary WAV audio data.

<ResponseExample>
```text 200 OK
Content-Type: audio/wav
Content-Disposition: attachment; filename="speech.wav"

[Binary WAV audio data]
```

```json 400 Bad Request
{
  "error": "INVALID_REQUEST",
  "message": "Text is required."
}
```
</ResponseExample>
