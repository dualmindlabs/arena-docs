---
openapi: "POST /api/arena/model-vote"
title: "Submit a vote"
---

| `voteChoice` | Meaning |
| :-- | :-- |
| `left` | `agent1` gave the better answer |
| `right` | `agent2` gave the better answer |
| `tie` | Both were good |
| `both-bad` | Neither was helpful |

<Warning>
  Votes are final: each user can vote once per `comparisonId`. A second vote is rejected with `VOTE_ERROR`.
</Warning>
