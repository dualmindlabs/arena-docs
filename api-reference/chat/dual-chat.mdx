---
openapi: "POST /api/arena/dualchat"
title: "Start a battle"
---

<Info>
  **Keep it blind.** The response includes `agent1.model`, `agent2.model` and `arena.models` so you can reveal names after a vote. Keep them hidden from voters until they vote, as the Arena does. See [Run a battle](/api-reference/guides/run-a-battle).
</Info>

| You want | Send |
| :-- | :-- |
| A blind random battle | `prompt` only (or `selectionMode: "random"`) |
| The leader vs a challenger | `selectionMode: "topper"` |
| Two models you choose (Side by Side) | `model1` **and** `model2` |
| To save it in a thread | `threadId` of a thread you own |

<Note>
  Both models run in parallel with a 60 second limit each. A model that fails or times out is replaced by a fallback model, and its `message` starts with `[System Note]`. Use a client timeout of at least 120 seconds.
</Note>
