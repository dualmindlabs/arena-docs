# Streaming Chat <Badge>Stable</Badge>

Stream AI model responses token-by-token using <Tooltip tip="Server-Sent Events — a standard for server-to-client streaming over HTTP">SSE</Tooltip>. Ideal for real-time chat interfaces where you want output to appear as the model generates it.

## Authentication <Badge variant="warning">Required</Badge>

<ParamField header="Authorization" type="string" required>
  ```
  Authorization: Bearer dm_test_xxxxxxxxxxxx
  ```
</ParamField>

## Request

<ParamField body="prompt" type="string" required>
  The prompt to send to the model.
</ParamField>

<ParamField body="model" type="string">
  A specific model ID, or `"auto"` for automatic selection.
</ParamField>

<ParamField body="temperature" type="number">
  Sampling temperature between `0.0` and `2.0`.
</ParamField>

<ParamField body="maxTokens" type="integer">
  Maximum number of tokens in the response.
</ParamField>

## Response Format

**Content-Type**: `text/event-stream`

Each event is delivered in the SSE format:
```
data: {json}\n\n
```

### Event Types

<ResponseField name="ai.stream.delta" type="object">
  An incremental text chunk as the model generates its response.

  ```json
  {
    "object": "ai.stream.delta",
    "delta": {
      "type": "output_text",
      "text": "chunk"
    }
  }
  ```
</ResponseField>

<ResponseField name="ai.stream.done" type="object">
  Emitted once when the stream completes successfully.

  ```json
  {
    "object": "ai.stream.done",
    "finish_reason": "stop",
    "usage": { "totalTokens": 135 }
  }
  ```
</ResponseField>

<ResponseField name="ai.error" type="object">
  Emitted if an error occurs during streaming.

  ```json
  {
    "object": "ai.error",
    "code": "STREAM_ERROR",
    "message": "Stream interrupted."
  }
  ```
</ResponseField>

<RequestExample>
```javascript JavaScript (Fetch API)
const response = await fetch('https://api.dualmind.ai/v1/chat/stream', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer dm_test_xxxxxxxxxxxx',
    'Content-Type': 'application/json',
    'Accept': 'text/event-stream'
  },
  body: JSON.stringify({
    prompt: 'Explain quantum computing',
    model: 'llama-3.3-70b'
  })
});

const reader = response.body.getReader();
const decoder = new TextDecoder();
let fullResponse = '';

while (true) {
  const { done, value } = await reader.read();
  if (done) break;
  
  const chunk = decoder.decode(value);
  const lines = chunk.split('\n\n');
  
  for (const line of lines) {
    if (line.startsWith('data: ')) {
      const event = JSON.parse(line.substring(6));
      
      if (event.object === 'ai.stream.delta') {
        fullResponse += event.delta.text;
        console.log(fullResponse); // Update UI
      } else if (event.object === 'ai.stream.done') {
        console.log('Stream complete');
      } else if (event.object === 'ai.error') {
        console.error(event.message);
      }
    }
  }
}
```

```python Python
import requests, json

response = requests.post(
    'https://api.dualmind.ai/v1/chat/stream',
    headers={
        'Authorization': 'Bearer dm_test_xxxxxxxxxxxx',
        'Content-Type': 'application/json',
        'Accept': 'text/event-stream'
    },
    json={'prompt': 'Explain quantum computing'},
    stream=True
)

for line in response.iter_lines():
    if line.startswith(b'data: '):
        event = json.loads(line[6:])
        if event['object'] == 'ai.stream.delta':
            print(event['delta']['text'], end='', flush=True)
        elif event['object'] == 'ai.stream.done':
            print('\n[Stream complete]')
```

## Notes

<Note>
Use the Fetch API with `ReadableStream` on the client side. The native `EventSource` API does not support POST requests or custom authorization headers.
</Note>

<Note>
Streaming responses are not automatically saved to conversation threads. If you need persistence, use the standard `/v1/chat` endpoint.
</Note>
