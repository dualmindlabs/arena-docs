---
openapi: "POST /api/arena/chat"
title: "Chat with one model"
---

Direct Chat with one model. Set `model` to a `modelName` or `modelId` from [List models](/api-reference/models/list-models), or `auto` to get a random Groq or Google AI Studio model. Want text as it's generated? Use [Stream a chat reply](/api-reference/chat/streaming).
