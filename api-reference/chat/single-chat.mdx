---
title: "Chat"
api: "POST https://api.dualmind.ai/v1/chat"
description: "Send a prompt to a single AI model and receive a response."
---

## Authentication

<ParamField header="Authorization" type="string" required>
  ```
  Authorization: Bearer dm_test_xxxxxxxxxxxx
  ```
</ParamField>

## Request

<ParamField body="prompt" type="string" required>
  The prompt to send to the model.
</ParamField>

<ParamField body="model" type="string">
  A specific model ID, or `"auto"` to let the platform select one. Defaults to `"auto"`.
</ParamField>

<ParamField body="threadId" type="string">
  Optionally associate this message with a conversation thread.
</ParamField>

<ParamField body="temperature" type="number">
  Sampling temperature between `0.0` and `2.0`.
</ParamField>

<ParamField body="maxTokens" type="integer">
  Maximum number of tokens in the response.
</ParamField>

<RequestExample>
```bash cURL
curl -X POST https://api.dualmind.ai/v1/chat \
  -H 'Authorization: Bearer dm_test_xxxxxxxxxxxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "prompt": "Explain quantum computing in simple terms",
    "model": "llama-3.3-70b",
    "temperature": 0.7
  }'
```

```javascript JavaScript
const response = await fetch('https://api.dualmind.ai/v1/chat', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer dm_test_xxxxxxxxxxxx',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    prompt: 'Explain quantum computing in simple terms',
    model: 'llama-3.3-70b',
    temperature: 0.7
  })
});
```

```python Python
import requests

requests.post(
    'https://api.dualmind.ai/v1/chat',
    headers={'Authorization': 'Bearer dm_test_xxxxxxxxxxxx'},
    json={'prompt': 'Explain quantum computing in simple terms', 'temperature': 0.7}
)
```
</RequestExample>

## Response

<ResponseField name="success" type="boolean">
  `true` on a successful completion.
</ResponseField>

<ResponseField name="message" type="string">
  The model's response text.
</ResponseField>

<ResponseField name="model" type="object">
  Metadata about the model that generated the response.

  <Expandable title="properties">
    <ResponseField name="name" type="string">Model identifier.</ResponseField>
    <ResponseField name="displayName" type="string">Human-readable name.</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="selectionMode" type="string">
  `"automatic"` if the platform selected the model, `"manual"` if you specified it.
</ResponseField>

<ResponseField name="latencyMs" type="integer">
  Time taken to generate the response in milliseconds.
</ResponseField>

<ResponseField name="usage" type="object">
  Token usage for this request.

  <Expandable title="properties">
    <ResponseField name="promptTokens" type="integer">Input tokens consumed.</ResponseField>
    <ResponseField name="completionTokens" type="integer">Output tokens generated.</ResponseField>
    <ResponseField name="totalTokens" type="integer">Sum of prompt and completion tokens.</ResponseField>
  </Expandable>
</ResponseField>

<ResponseExample>
```json 200 OK
{
  "success": true,
  "message": "Quantum computing uses qubits which can exist in superposition...",
  "model": {
    "name": "llama-3.3-70b",
    "displayName": "Llama 3.3 70B"
  },
  "selectionMode": "manual",
  "latencyMs": 1245,
  "usage": {
    "promptTokens": 15,
    "completionTokens": 120,
    "totalTokens": 135
  }
}
```

```json 400 Bad Request
{
  "error": "INVALID_REQUEST",
  "message": "Prompt is required."
}
```

```json 401 Unauthorized
{
  "error": "UNAUTHORIZED",
  "message": "Invalid or missing token."
}
```
</ResponseExample>
