The Arena app is a client of a public REST API. Everything you can do in the Arena (start a battle, vote, browse the leaderboard, manage threads) you can do over HTTPS.

<CardGroup cols={2}>
  <Card title="Base URL" icon="globe">
    `{{apiBase}}`
  </Card>
  <Card title="Format" icon="braces">
    JSON in, JSON out (camelCase). Streaming uses Server-Sent Events.
  </Card>
  <Card title="Auth" icon="key-round">
    `Authorization: Bearer <access token>` from your Arena session. [Details](/api-reference/authentication).
  </Card>
  <Card title="Status" icon="activity">
    [`GET /health`](/api-reference/utilities/health) is public and always cheap to call.
  </Card>
</CardGroup>

## Your first request

No token needed for the leaderboard:

<CodeGroup>
```bash cURL
curl {{apiBase}}/api/arena/model-stats
```

```javascript JavaScript
const res = await fetch("{{apiBase}}/api/arena/model-stats");
console.log((await res.json()).items[0]);
```

```python Python
import requests
print(requests.get("{{apiBase}}/api/arena/model-stats", timeout=30).json()["items"][0])
```
</CodeGroup>

## Conventions

<AccordionGroup>
  <Accordion title="IDs" icon="fingerprint">
    Threads, messages, comparisons and models use UUIDs. Model fields (`model`, `model1`, `model2`) accept either a model's `modelName` or its `modelId`.
  </Accordion>
  <Accordion title="Timestamps" icon="clock">
    ISO 8601 in UTC, e.g. `2026-10-17T12:00:00Z`.
  </Accordion>
  <Accordion title="Null fields" icon="circle-off">
    Fields with no value are left out of responses rather than sent as `null`.
  </Accordion>
  <Accordion title="Timeouts" icon="hourglass">
    Each model call is capped at 60 seconds, after which a fallback model answers. Give battle requests a client timeout of at least 120 seconds.
  </Accordion>
  <Accordion title="Correlation IDs" icon="tag">
    Every response carries an `X-Correlation-Id` header. Include it when you report a problem.
  </Accordion>
  <Accordion title="CORS" icon="globe-lock">
    Browser requests from any origin are allowed.
  </Accordion>
</AccordionGroup>

## Rate limits and fair use

The API is shared with everyone using the Arena, so please keep usage at interactive volumes.

<AccordionGroup>
  <Accordion title="What counts as fair use" icon="scale">
    Battles and chats driven by people, scripts that run a handful of prompts, and dashboards that read the leaderboard every few minutes are all fine. Bulk benchmarking, load tests and scraping are not; [get in touch](mailto:hello@dualmindlab.tech) first.
  </Accordion>
  <Accordion title="Be gentle with the leaderboard" icon="trophy">
    The leaderboard changes slowly. Cache `GET /api/arena/model-stats` for at least a minute instead of polling it in a tight loop.
  </Accordion>
  <Accordion title="Expect limits to arrive" icon="gauge">
    Published per-user limits are planned. When they arrive, requests over the limit will get `429 Too Many Requests`; back off and retry later. Changes will be announced in the [changelog](/changelog).
  </Accordion>
</AccordionGroup>
