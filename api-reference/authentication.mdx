The API uses the same sign-in as the Arena. When you sign in, Supabase Auth issues a short-lived **access token** (a JWT). Send it as a Bearer token:

```http
Authorization: Bearer <access token>
```

## Which endpoints need a token

| Needs a token | No token needed |
| :-- | :-- |
| Battles and chat (`/api/arena/dualchat`, `/chat`, `/chat/stream`) | Leaderboard (`GET /api/arena/model-stats`) |
| Voting (`POST /api/arena/model-vote`) | Health (`GET /health`) |
| Models (`GET /api/models`) | Feature flags (`GET /api/settings/feature-flag/{key}`) |
| Your threads (list, create, rename, share, delete) | Shared threads (`public` or `unlisted`) |

## Get your token

<Steps>
  <Step title="Sign in to the Arena">
    Open [arena.dualmindlab.tech](https://arena.dualmindlab.tech) and sign in.
  </Step>
  <Step title="Open the browser console">
    Press <kbd>F12</kbd> (or <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>J</kbd> on a Mac) and choose **Console**.
  </Step>
  <Step title="Copy the token">
    Run this in the console. It copies the current access token to your clipboard:

    ```javascript
    copy(await DualMindAuth.getAccessToken())
    ```
  </Step>
  <Step title="Keep it out of your code">
    Store it in an environment variable, not in source control:

    ```bash
    export DUALMIND_TOKEN="eyJhbGciOi..."
    ```
  </Step>
</Steps>

## Check that it works

<CodeGroup>
```bash cURL
curl -i {{apiBase}}/api/models \
  -H "Authorization: Bearer $DUALMIND_TOKEN"
```

```javascript JavaScript
const res = await fetch("{{apiBase}}/api/models", {
  headers: { Authorization: `Bearer ${process.env.DUALMIND_TOKEN}` },
});
console.log(res.status, res.ok ? (await res.json()).items.length + " models" : res.headers.get("www-authenticate"));
```

```python Python
import os, requests

r = requests.get(
    "{{apiBase}}/api/models",
    headers={"Authorization": f"Bearer {os.environ['DUALMIND_TOKEN']}"},
    timeout=30,
)
print(r.status_code, len(r.json()["items"]) if r.ok else r.headers.get("WWW-Authenticate"))
```
</CodeGroup>

A `200` with a list of models means you're in. A `401` means the token is missing, malformed or expired.

## Token lifetime

<AccordionGroup>
  <Accordion title="Tokens expire" icon="hourglass">
    Access tokens are short-lived (typically about an hour). The Arena refreshes its own session automatically; for scripts, copy a fresh token when you get a `401`.
  </Accordion>
  <Accordion title="Reading a 401" icon="circle-alert">
    Authentication failures return `401` with an empty body. The `WWW-Authenticate` response header says why, for example `Bearer error="invalid_token", error_description="The token expired..."`.
  </Accordion>
  <Accordion title="Long-lived API keys" icon="key">
    Personal API keys for scripts and integrations are planned. See the [roadmap](/roadmap).
  </Accordion>
</AccordionGroup>
