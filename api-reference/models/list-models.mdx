---
title: "List Models"
api: "GET https://api.dualmind.ai/v1/models"
description: "Retrieve the list of active AI models available for comparison."
---

## Authentication

<ParamField header="Authorization" type="string" required>
  ```
  Authorization: Bearer dm_test_xxxxxxxxxxxx
  ```
</ParamField>

## Response

<ResponseField name="items" type="array">
  An array of active model objects available for comparison.

  <Expandable title="Model object">
    <ResponseField name="modelId" type="string">
      Unique model identifier.
    </ResponseField>
    <ResponseField name="modelName" type="string">
      Model slug used when specifying a model in API requests (e.g., `llama-3.3-70b`).
    </ResponseField>
    <ResponseField name="displayName" type="string">
      Human-readable model name for display.
    </ResponseField>
    <ResponseField name="status" type="string">
      Always `"active"` for models returned by this endpoint.
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl https://api.dualmind.ai/v1/models \
  -H 'Authorization: Bearer dm_test_xxxxxxxxxxxx'
```

```javascript JavaScript
const response = await fetch('https://api.dualmind.ai/v1/models', {
  headers: { 'Authorization': 'Bearer dm_test_xxxxxxxxxxxx' }
});
const { items } = await response.json();
```

```python Python
import requests

models = requests.get(
    'https://api.dualmind.ai/v1/models',
    headers={'Authorization': 'Bearer dm_test_xxxxxxxxxxxx'}
).json()
```
</RequestExample>
