---
openapi: "PATCH /api/threads/{threadId}/visibility"
title: "Share a thread"
---

| `visibility` | Who can read it |
| :-- | :-- |
| `private` | Only you |
| `unlisted` | Anyone with the link |
| `public` | Anyone |

The Arena's share link for a thread is `https://arena.dualmindlab.tech/share/{threadId}`.
